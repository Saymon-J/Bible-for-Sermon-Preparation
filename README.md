# Bible Reader (домашняя читалка Библии для ПК)

Клон MyBible (mybible.zone) под ПК. Читает модули MyBible `*.sqlite3` из папки `module`
с подпапками `переводы`, `словари`, `комментарии`. Старая плоская папка «переводы»
раскладывается по типам автоматически при первом запуске (занятые файлы остаются
на месте и продолжают сканироваться).
Только стандартная библиотека Python (tkinter + sqlite3), ноль рантайм-зависимостей.

- Запуск: `Библия.exe` в корне проекта (собран PyInstaller, Python не нужен) — exe ищет
  `module/`, `src/` и `app/config.json` рядом с собой; либо ярлык «Библия» на рабочем столе
  (цель — pythonw, иконка `app\icon.ico`), `start.bat` или `python app/bible.py`.
  Если Python переустановится в другой путь — пересоздать ярлык (TargetPath).
- Версия: `python app/bible.py --version` (или `Библия.exe --version`), там же в
  «Файл → О программе…». История — внизу этого файла.
- Самопроверка без GUI: `python app/bible.py --selftest` (exe: `Библия.exe --selftest`)
- Код разбит по модулям в `app/` (см. «Структура кода»). Состояние окон: `app/config.json`
  (пользовательское!, общее у скрипта и exe)

## Структура кода (app/, плоские модули, без пакетов)

Зависимости идут сверху вниз, циклов нет. `python app/bible.py` кладёт `app/` в `sys.path`,
поэтому импорты простые (`from markup import …`), без `__init__.py`.

| Модуль | Что внутри |
|---|---|
| `bible.py` | точка входа: `main()`, `--selftest` / `--version` |
| `paths.py` | версия, FROZEN, все пути (модули, конфиг, логотип) |
| `theme.py` | темы Fluent 2, шрифт интерфейса |
| `markup.py` | разбор разметки MyBible, чистый текст, формат копирования |
| `refs.py` | ссылки на места Писания, группы/разделы книг, конкорданс, словари |
| `module.py` | класс `Module` (sqlite), скан папки `module` |
| `icon.py` | PNG-кодек, обрезка фона, бокс-ресемпл, ICO 16–256 |
| `style.py` | `apply_fluent_style()` — все ttk-стили Fluent |
| `windows.py` | окна: комментарий, поиск, урок, словарь |
| `reader.py` | окно читалки, плитки книг, Стронг, сравнение переводов |
| `application.py` | класс `App`: окна, конфиг, темы, Ctrl+C, «стих из буфера» |
| `selftest.py` | самопроверка без GUI |

## Модули (сканируются автоматически, тип — по таблицам внутри файла, папка — где искать)

Добавлять модули можно из программы: «Файл → Добавить модуль…» или кнопка «+ Модуль»
в тулбаре — выбрать файлы `*.sqlite3`, тип каждого определится по таблицам, копируются
в нужную подпапку `module`, список обновляется сразу. Уже установленное имя файла
не перезаписывается (старый может быть открыт приложением; для замены удалите файл
в `module/<тип>` и добавьте снова).

| Таблицы | Тип | Примеры в папке |
|---|---|---|
| `verses`+`books` | перевод | MDR, NRT, RST+ (синод. со Стронгом), РСП |
| `commentaries` | комментарий | NRT, RST+, РСП, Баркли, Кулаков, МакАртур, «Стронг по стихам» |
| `dictionaries`/`dictionary` | словарь Стронга | Лексикон (СимфСтр, Стр., Стронг) — темы `H7225`/`G26` |

Нумерация книг во всех модулях одна — 10–730 (bibleonline-схема), прямое сопоставление.
Порядок книг: `sorting_order` если есть (NRT — православный порядок НЗ), иначе `book_number`.
Диапазоны в `commentaries`: пустое «до» может быть NULL, `''` или `'0'` — все три обработаны.
Колонки `commentaries` различаются: у части нет `marker` — запрос адаптивный.

## Что умеет (сделано)

- Каждый стих с новой строки; заголовки разделов (`stories`) жирным по центру; «Псалом N» для Псалтыри (>100 глав).
- Клик по стиху — выделение, Ctrl+клик — добавить, Shift+клик — диапазон; рядом всплывает кнопка «Скопировать».
- Копирование в формате MyBible: заголовок «Книга Г:1-5, 8, 11-14» + стихи с номерами.
  Галочка «Вид → Копировать стихи в одну строку» (хранится в конфиге): стихи идут друг
  за другом через пробел («1 текст 2 текст»), а не каждый с новой строки; действует
  везде — читалка, «стих из буфера», «Собрать урок».
- Ctrl+C/Ctrl+с — через диспетчер по фокусу окна (читалка / комментарий / карточка Стронга / введение).
  Русская раскладка ловится по keycode 67 (физическая клавиша C) + все формы keysym + Ctrl+Insert.
- Поиск (Ctrl+F, кнопка «Поиск»): запрос, область поиска (14 категорий: текущая книга, вся Библия,
  ВЗ/НЗ, Пятикнижие, исторические, поэтические, пророки/большие/малые, Евангелия, Деяния,
  Послания, Послания Павла — группы книг по номерам 10–730), двойной клик — переход с подсветкой,
  результатов без ограничения. Регистронезависимо для кириллицы (python lower, не SQLite LIKE).
  Индекс перевода строится при первом поиске (~2 с, кэш в модуле).
  Чекбокс «по комментариям» — тот же поиск по текстам всех комментариев (область действует и там);
  строка результата подписана именем толкователя, двойной клик — переход к месту.
- Сравнение переводов: Ctrl+двойной клик по стиху — карточка со стихом во всех переводах
  подряд (название перевода синим, текст под ним), с бегунком; недостающие переводы пропускаются.
- Режим чтения (F11 или Вид → «Режим чтения»): тулбар и меню спрятаны, только текст;
  F11 или Esc — обратно (Esc вне режима снимает выделение стихов).
- Собрать урок (кнопка «Урок» в тулбаре, Файл → «Собрать урок…»): вставляете текст со ссылками —
  каждая разворачивается в цитату с полным именем книги («Ин 15:13» → «Иоанна 15:13» + стихи;
  ссылка на главу без стиха даёт главу целиком; нераспознанное остаётся как было).
  Перевод — первого окна; «Копировать результат» кладёт готовый документ в буфер.
- Словарь (кнопка 📖, Вид → «Словарь…»): слово — статьи всех словарей, где оно встречается
  (тема или текст, регистронезависимо, до 200); номер Стронга (G26, H7225, голое число) — статья
  из словаря + все стихи перевода со Стронгом (RST+), где номер стоит в тексте, двойной клик —
  переход. Номера в статьях кликабельны (открывают другие статьи).
- Стих из буфера (тумблер 📋 в тулбаре рядом с «Поиск» и Вид → «Стих из буфера», хранится в конфиге;
  включён — зелёная рамка):
  скопировали в любом приложении
  ссылку вида «Ин 15:13», «Иоанна 15:13-16», «Псалом 118», «1 Кор 13:4-7», «откр 3:20» — в углу
  экрана всплывает текст стиха (перевод первого окна) с кнопками «Копировать» / «Открыть в читалке»,
  заголовок всегда в полной чистой форме («Иоанна 15:13», не «Ин 15:13»; «От Иоанна» → «Иоанна»,
  «Послание римлянам» → «Римлянам», «1-е посл. Петра» → «1-Петра»), копирование — в том же формате,
  авто-закрытие 2 минуты, фокус не крадётся; длинный текст — в прокручиваемом поле до 14 строк,
  за границы экрана окно не уходит. Реагирует на событие Windows о смене буфера (в т.ч.
  на повторное копирование той же ссылки; опрос раз в 0.9 с — запасной путь), при включении
  галочки подхватывает ссылку, уже лежащую в буфере. Понимает сокращения и полные имена книг
  (алиасы берутся из модуля: «от Иоанна» → «Иоанна»), таблицу сокращений на все 66 книг:
  русские формы («Мф/Мат/Мт/Мтф», «Флп», «1Кор», «Апок», «Екклесиаст», «Песнь Песней»…),
  английские аббревиатуры и полные имена (Mt, Mk, Jn, 1Cor, Gen, 1Sam, Ps, Rev, John 3:16),
  дореволюционная орфография ѣ/ѳ/і/ъ («Матѳея 5:3», «Дѣянія 2:14», «Іоаннъ»); формы
  «1-Петра»/«1Петра»/«1 Петра», слова «глава/гл», «стих/ст» («Ин гл 15 ст 13»), главу и стих
  через пробел, уникальные префиксы, «см. Ин 15:13» внутри строки, список ссылок
  «Притчи 9:9; 12:1» (глава после «;»/«,» с двоеточием наследует книгу); однострочные ссылки
  до 200 знаков, иначе игнорирует. Рискованные омоформы («на», «из», «от», «бы», «ес»)
  в таблицу не входят. Той же таблицей пользуется «Собрать урок».
  Выключено по умолчанию.
- Перекрёстные ссылки в окнах комментариев кликабельны: `<x>` и `<a href='B:…'>`
  (NRT, МакАртур, Кулаков и др.; префикс `C:@` тоже). Имя книги подставляется из самой
  ссылки («Мар. 3:13-19», не «3:13-19»). Клик открывает отрывок в новом окне читалки
  с подсветкой стиха — текущее окно и комментарий на месте. Двойной клик по стиху
  конкорданса в словаре — так же в новом окне.
- Карточки Стронга: клик по номеру в тексте (RST+) открывает статью. Источники по порядку:
  1) модуль-словарь (таблица `dictionary`/`dictionaries`; голому номеру подставляется префикс
  H (ВЗ) / G (НЗ) по книге стиха; первый по алфавиту словарь приоритетнее — сейчас «Полный лексикон
  по Стронгу и Дворецкому»); 2) «Словарь Стронга по стихам» (`Стронг-к.commentaries`):
  k-й номер в стихе ↔ k-е слово глоссария стиха (порядок слов совпадает).
  Ссылки-синонимы (`<a href='S:H136'>`) → кликабельные H136; библейские ссылки (`B:480 8:12`) → «Мар. 8:12».
- Поиск без лимка результатов; области — 14 категорий (см. выше).
- Введения к книгам (`introductions`, есть в NRT и РСП): меню «Вид → Введение к книге».
- История отрывков читалки (точность до стиха; комментарии/поиск/словари не индексируются):
  кнопка ⟲ в тулбаре — клик на отрывок назад, зажатие (~0.5 с) — окно списка
  (двойной клик/Enter — перейти); также меню «Переход» и Alt+←/→.
- Меню «Файл → Обновить переводы»: перечитать папку `module` без перезапуска.
- Добавление модулей из программы («Файл → Добавить модуль…», кнопка «+ Модуль»):
  выбор файлов `*.sqlite3`, тип (перевод/словарь/комментарий) — по таблицам внутри
  файла, копирование в нужную подпапку `module`, список обновляется сразу; мусорные
  файлы и дубли отбиваются с сообщением.
- Окно «Модули…» («Файл», две вкладки). «Скачать» — каталог ph4.ru:
  список всех модулей MyBible с сайта (переводы, комментарии, словари), фильтр по
  названию, выбор нескольких; zip скачивается, все `*.sqlite3` из него ставятся по
  типам, список обновляется сразу. Сеть — в фоне, окно не замирает.
  «Скачанные» — установленные модули по типам; выбранные удаляются (с подтверждением;
  панели и окна, сидевшие на удалённом модуле, переезжают на оставшиеся;
  последний перевод удалить нельзя).
- Оформление Microsoft Fluent 2: Segoe UI Variable для интерфейса, фирменный синий
  (#0f6cbd / #479ef5 в тёмной), плоские кнопки (вторичные с рамкой 1px, главные — синие,
  тулбар — прозрачные с подсветкой на ховере), текст — карточки с рамкой на серой подложке,
  тонкие бегунки без видимых стрелок. Радиусов в ttk нет — элементы плоские.
- Темы оформления («Вид → Тема», сохраняется в конфиге): Светлая и Тёмная (Fluent 2),
  «Пергамент» — состаренная бумага с коричневым текстом и терракотовыми номерами
  стихов, как в MyBible; «Сепия» — мягкая серо-бежевая; «Ночь» — чистый чёрный;
  «Полночь» — тёмно-синяя. Окна поиска при смене темы закрываются (не перекрашиваются
  на лету).
- Переход плитками в одном окне (как в MyBible): книги по разделам (Закон, История,
  Псалмы и премудрость, пророки, Евангелия, …) → главы книги → стихи главы;
  «←» и Esc — на шаг назад/закрыть. Плитки глав всегда с первой (текущая подсвечена
  синим). Выбор стиха открывает главу и проматывает читалку к этому стиху —
  без жёлтой подсветки (она осталась только у переходов из поиска и по ссылкам
  из комментариев; Esc снимает и её). Открывается кнопками книги и главы
  в тулбаре (и такими же в шапках панелей); ◀/▶ и Ctrl+←/→ через границы книг;
  Ctrl+колесо — шрифт.
- Узкое окно: вторичные кнопки тулбара (Поиск … «Синхр.») сворачиваются с конца в
  меню «⋯» и возвращаются при расширении; всегда видны перевод/книга/глава/⟲/☰/◀▶.
  Минимальный размер окна 620×420 (было 1100×540 — кнопки вылезали и не нажимались).
- Панели чтения (кнопка ☰ в тулбаре): окно делится до трёх панелей, делящих всю
  ширину окна поровну (разделители можно тянуть мышью); в шапке каждой панели —
  свои книга, глава и перевод, ✕ закрывает панель. Тулбар управляет панелью,
  куда кликнули последней (она подсвечена синей рамкой).
  Отдельное окно — Вид → «+ Окно (новое)».
- Тумблер «⇄» синхронизирует панели одного окна: переход по книге/главе/стиху и
  прокрутка (колесо, бегунок, клавиши) мгновенно повторяются в остальных панелях
  этого же окна, выравниваясь по стиху у верхнего края; книга находится в каждом
  переводе по номеру. Независимые окна читалок («+ Окно», ссылки комментариев,
  поиск) не затрагиваются.
- Окна комментариев: кнопка «Комментарий» → отдельное синхронизируемое окно, свой толкователь,
  можно несколько (Баркли + МакАртур рядом).
- Стронг: чекбокс показывает `<S>`-номера (RST+), клик по номеру — карточка
  (с бегунком прокрутки; статья целиком читается даже длинная).
- Сноски `<f>` из текста убраны; их тексты берутся из модулей-комментариев по verse+marker.
  Маркер-только (`[1]` без текста) не показывается.
- Разметка: `<pb/>`,`<br/>` — абзацы; `<t>` — поэзия с отступом; `<J>` — красным; `<i>/<e>` — курсив;
  `<S>`,`<m>` — вырезаются (S показывается при включённом чекбоксе); прочие теги — вырезаются.
- Иконка приложения: из `src/logo2.png` без полей и в высоком качестве. Конвейер (чистый
  Python + zlib): PNG-декодер, фон отрезается заливкой от краёв (стал прозрачным), контент
  обрезается по рамке и вписывается в квадрат 256 без искажений, бокс-фильтр с учётом альфы
  даёт размеры 16–256. Результат кэшируется в `app/icon.png` + `app/icon.ico` (7 PNG-слоёв),
  пересборка ~3 с только при смене логотипа; окну даются фото 256/48/32/16 — Tk выбирает
  ближайший. Запасная — рисуется программно.
  Файл `app/icon.ico` — для ярлыка: свойства ярлыка → Сменить значок → указать файл.
- Шрифт: меню «Вид → Шрифт…» — гарнитура (все установленные в системе) и размер, живой предпросмотр,
  применяется ко всем окнам, сохраняется в конфиге (`font_family`, `font_size`).
  Также Ctrl+колесо меняет размер. Пропорции: карточки Стронга = размер+1, комментарии = размер−2.
- Состояние (окна, позиции, Стронг, комментарии, тема, шрифт) сохраняется при выходе.

## Сборка exe (PyInstaller, только для сборки — рантайм остаётся stdlib)

```
pip install pyinstaller
python -m PyInstaller --onefile --windowed --icon="F:/zcode/Bible/app/icon.ico" \
  --name "Библия" --distpath dist --workpath build --specpath build app/bible.py
cp dist/Библия.exe .
rm -rf build dist
```

Пути внутри exe резолвятся от самого файла (`sys.frozen`): exe кладётся в корень проекта,
рядом с `module/` и `src/`; состояние общее — `app/config.json`. Иконку писать в exe
нужно абсолютным путём (spec-папка ломает относительный). После пересборки прогнать
`Библия.exe --selftest`.

## Договорённости для будущих сессий (важно)

- Любое окно или область с потенциально длинным текстом (карточки Стронга, статьи словаря,
  урок, поиск, введения, комментарии, плитки книг, всплывающая карточка стиха) обязано иметь
  бегунок прокрутки и/или ограничение высоты по экрану. Новые окна — тоже, без исключений:
  сначала виджет текста/списка, рядом `ttk.Scrollbar` с `yview`/`yscrollcommand`.
- `app/config.json` — живое состояние пользователя. Любой GUI-тест: бэкап → unlink → тест →
  восстановить байты → проверить равенство. Один раз уже теряли. (`--selftest-gui` конфиг
  только читает — on_exit не зовётся, бэкап не нужен.)
- После правок кода: `python -m pyflakes app/*.py` (потерянные имена после переносов
  между модулями) и `python app/bible.py --selftest-gui` (каждое окно живьём).
- Синтетика `event_generate` с модификаторами (Ctrl+…) в этом Tk не запускает бинды —
  тестировать диспетчер прямыми вызовами с фейковыми event-объектами.
- `dlineinfo`/`bbox` дают None без `update()` после рендера — в тестах звать `root.update()`.
- Окно читалки №1 живёт на root: `w.close()` на нём убивает всё приложение.
- Ненулевая логика обязана иметь проверки в `--selftest` (без GUI, без фреймворков).
